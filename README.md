## About

This repo contains scripts and control files necessary to reproduce the analyses in Gaughran et al. 2026. 

## Paleomix pipeline

Example control (.yml) files used in the Paleomix pipeline. MMS_greece.yml contains the settings used for all modern samples and MMS_italy.yml contains the settings used for historical museum samples. 

## BPP

Scripts to generate aligned genomic segments can be found at https://github.com/sjgaughran/tortoise-phylogenomics. 

Control scripts for BPP model A00 and BPP model A01 are provided, as is a population mapping file for the included samples. 

## Mutational load

Detailed methodology and scripts for the mutational load analyses can be found at https://github.com/sjgaughran/mutation-accumulation.
